# ADR-001. Выбор стека: Django + Django Ninja (пример заполнения)

**Статус:** принято
**Дата:** 2026-09-03

## Контекст
Команда из 3–4 студентов с неровным уровнем Python, два месяца, два очных интенсива. Нужны: пользователи и админка «из коробки»,
REST API с автодокументацией, простая интеграция очереди. Преподаватель — практик Django, значит помощь на воркшопах быстрая.

## Рассмотренные варианты
1. **Django + Django Ninja** — auth, admin, ORM, миграции бесплатно; Ninja даёт pydantic-схемы и Swagger. Минус: «магия» Django для новичков.
2. **FastAPI + SQLAlchemy** — прозрачнее и легче; минус: auth, admin, миграции (alembic) писать/настраивать самим — для слабой команды это недели.
3. **Flask** — минимализм; минус: всё то же, что у FastAPI, плюс нет автодокументации API.

## Решение
Django + Django Ninja. Экономим время на инфраструктуре и тратим его на ядро и архитектуру.

## Последствия
Учим структуру Django-проекта на занятии 6; принимаем его соглашения (apps, migrations). Сильная команда может выбрать FastAPI,
если сама закроет auth/admin — фиксируется отдельным ADR.
