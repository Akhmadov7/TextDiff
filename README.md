# TextDiff

Сервис статистического сравнения текстовых корпусов. Специализация темы курса №5
(«Статистический анализ загружаемого набора данных») на текстовых данных.

Курс «Архитектура и проектирование веб-приложений», Филиал МГУ в г. Грозном, 2026.
Стартовый репозиторий: https://github.com/alexshep-lab/calc-service-starter

## Что считаем

Пользователь загружает CSV с текстами, разбитыми на две группы (например, отзывы
«позитивные»/«негативные», тексты двух авторов и т.п.). Ядро строит по каждой группе
лексические статистики (длина текста, лексическое разнообразие TTR, средняя длина слова,
частоты слов) и проверяет гипотезу о различии групп статистическим тестом
(Манна-Уитни или t-тест). На межсессии 1 добавляются регрессия по закону Ципфа и
попарное сравнение текстов по TF-IDF.

## Вход / выход

- **Вход:** CSV (колонки `text`, `group` — имена настраиваются в форме), выбор теста.
- **Выход:** таблица статистик по группам, значение теста и p-value, топ частых слов.

## Быстрый старт

```
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env        # Windows
# cp .env.example .env        # Linux/macOS
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

http://127.0.0.1:8000 — список задач; `/tasks/new/` — форма; `/api/docs` — Swagger UI.

Проверки: `pytest -q`, `pytest core -q`, `ruff check .`, `python -m core example_input.json`.

## Структура

```
core/        ядро (без Django): run(params) -> dict, CLI, тесты на эталонах
web/         модель Task, формы, views, services.py
api/         REST API (Django Ninja): создать/статус/результат/список задач
templates/   форма загрузки, список задач, страница результата
docs/        architecture.md, adr/ (решения), er-diagram.md
```
