# Python-выравнивание (занятие 3, уровень «база»)

Восемь задач. В `tasks.py` — заглушки функций, в `test_tasks.py` — проверки. Запуск: `pytest warmup -q`.
Задача сделана, когда её тест зелёный. Порядок — любой. AI-ассистентом пользоваться можно, но правило то же: объясни каждую строку соседу.

| # | Функция | Что проверяет |
|---|---|---|
| 1 | `mean(values)` | функции, циклы, деление на ноль |
| 2 | `word_count(text)` | строки, словари |
| 3 | `parse_params(line)` | разбор строки `a=1;b=2` в dict с числами |
| 4 | `Stats` | класс с методами `add` / `summary` |
| 5 | `read_numbers(path)` | чтение файла, пропуск плохих строк |
| 6 | `safe_div(a, b)` | исключения |
| 7 | `trapezoid(f, a, b, n)` | передача функции как аргумента |
| 8 | `to_json_line(d)` | модуль json, сортировка ключей |

Шпаргалка — в `cheatsheet.md`.
